# 01 — Ecosystem

## Purpose of this document

This directory holds full Analyst-stage research reports for **01 — Ecosystem**.

It maps the world we are entering: existing tools, prior attempts, active projects, research groups, communities, and anyone else working on Tigrinya or closely related language technology.

## Why this domain exists

Reuse-first (P-1) is impossible without knowing what exists. This domain is also where we discover collaborators and avoid duplicating work someone else has already done well — a serious risk in a small ecosystem where efforts are scattered and poorly indexed.

## Research questions this domain must answer

- What Tigrinya language technology exists today, and how good is it?
- What has been attempted before and abandoned? Why?
- Which research groups, universities, and individuals work on Tigrinya or Ethio-Semitic NLP?
- What community resources exist — dictionaries, corpora, keyboards, fonts, spell checkers?
- What do the adjacent ecosystems (Amharic, Tigre, Ge'ez) have that could transfer?
- Which commercial products claim Tigrinya support, and does it actually work?
- Where are the gaps nobody is filling?
- Who would be a collaborator rather than a competitor?

Every report in this directory must also answer the nine questions in
[`../../CHECKLIST.md`](../../CHECKLIST.md).

## How to use this directory

1. Check [`../../summaries/`](../../summaries/) first — the answer may already exist.
2. Run a **Scout** pass to map the option space; write the short summary.
3. Run an **Analyst** pass on the shortlist using
   [`../../templates/research_report_template.md`](../../templates/research_report_template.md).
4. Write the report here as `NNN-slug.md`.
5. Write the ≤2-page summary to `../../summaries/NNN-slug.md`. **The report is
   not finished without it.**
6. Hand to the **Architect** stage: record decisions in
   [`../../../decisions/DECISIONS.md`](../../../decisions/DECISIONS.md).
