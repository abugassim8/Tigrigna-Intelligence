# 11 — Business and Sustainability

## Purpose of this document

This directory holds full Analyst-stage research reports for **11 — Business and Sustainability**.

It covers how the project sustains itself: funding, licensing, governance, community, and long-term viability.

## Why this domain exists

Infrastructure that dies is worse than infrastructure that never existed, because people built on it. This domain asks how the project stays alive for years — a question that is easy to defer indefinitely and expensive to answer late. It also owns the licence decision, which is deliberately deferred until data and model strategy are settled, because it interacts with the licensing of everything we adopt.

## Research questions this domain must answer

- What licence should the project use, and how does it interact with the licences of models and data we adopt?
- What sustainability models are realistic — grants, sponsorship, institutional support, commercial services, or a mix?
- Who are the potential funders and institutional partners for Tigrinya language technology?
- What is the governance model, and who decides what?
- How does the project attract and retain contributors?
- What is released openly and what, if anything, is not — and how does that square with **G-11**?
- What are the legal considerations around data, licensing, and cross-border use?
- What happens to the platform if the current maintainers stop?
- What is the minimum annual cost to keep the platform alive and current?

Every report in this directory must also answer the nine questions in
[`../../CHECKLIST.md`](../../CHECKLIST.md).

## How to use this directory

1. Check [`../../summaries/`](../../summaries/) first — the answer may already exist.
2. Run a **Scout** pass to map the option space; write the short summary.
3. Run an **Analyst** pass on the shortlist using
   [`../../templates/research_report_template.md`](../../templates/research_report_template.md).
4. Write the report here as `NNN-slug.md`.
5. Write the ≤2-page summary to `../../summaries/NNN-slug.md`. **The report is
   not finished without it.**
6. Hand to the **Architect** stage: record decisions in
   [`../../../decisions/DECISIONS.md`](../../../decisions/DECISIONS.md).
